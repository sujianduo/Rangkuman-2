第一到第三课内容概要

1. 书 : shū : Buku
2. 书包 : shū bāo : tas sekolah
3. 尺子 : chǐ zi : penggaris
4. 剪刀 : jiǎn dāo : gunting
5. 卷笔刀 : juǎn bǐ dāo : rautan
6. 铅笔 : qiān bǐ : pensil
7. 桌子 : zhuō zi : meja 8. 椅子 : yǐ zi : kursi
9. 我 : wǒ : saya
10. 有 : yǒu : punya
wǒ yǒu shū bāo
1. 我 有 书 包 。
Saya punya tas sekolah.
wǒ méi yǒu jiǎn dāo
2. 我 没 有 剪 刀 。
Saya tidak punya gunting.
wǒ yǒu yī zhī qiān bǐ
3. 我 有 一 支 铅 笔 。
Saya punya 1 batang pensil.
wǒ méi yǒu yuán zhū bǐ
4. 我 没 有 圆 珠 笔 。
Saya tidak punya pulpen.
wǒ yǒu yī zhānɡ zhuō zi
5. 我 有 一 张 桌 子 。
Saya punya 1 buah meja.
